STEP-BY-STEP

一步一步，
完成門市設定。

以下教學使用功能名稱描述操作方向；實際按鈕位置及文字可能依 App 版本略有不同。

01
啟動設定

首次使用與建立管理員

首次開啟 OUPOS，依畫面完成商家與管理員的基本設定。

  1. 開啟 OUPOS，填入商家名稱。
  2. 建立管理員帳號並設定登入密碼。
  3. 確認設定後進入主畫面，保管好管理員帳號資料。
管理員密碼用於保護後續的管理功能。
02
菜單管理

建立商品分類與價格

先建立分類，再新增對應商品與售價。

  1. 使用管理員帳號進入菜單或商品管理相關畫面。
  2. 新增分類，例如「飲品」「主食」。
  3. 在分類中建立商品，填入商品名稱與價格，完成儲存。
  4. 返回點餐畫面確認分類及商品顯示正確。
分類、價格與商品資訊保存在 iPad 本機。
03
配料設定

新增配料群組

將常用加料與適用商品整理成可選擇的配料。

  1. 在管理功能中新增配料群組，設定群組名稱及選擇規則。
  2. 新增配料項目與需要的加價金額。
  3. 設定配料群組適用的分類或商品。
  4. 在點餐畫面測試選擇配料並確認金額。
匯入或調整後，請檢查配料規則是否符合實際菜單。
04
日常收銀

點餐、結帳與訂單紀錄

從商品選擇到完成收款，將流程維持在同一套 POS 中。

  1. 進入點餐畫面，選擇商品、數量及適用配料。
  2. 確認購物車內容與應收金額。
  3. 依實際交易選擇付款方式並完成結帳。
  4. 透過訂單紀錄或報表功能查看已建立的訂單。
請在正式收款前核對品項、價格與付款方式。
05
庫存狀態

標記售完與恢復供應

暫停售完品項供應，重新備貨後再恢復。

  1. 找到需要調整的商品。
  2. 將商品狀態設為「售完」；售完商品不可再加入購物車。
  3. 商品恢復供應後，取消售完狀態。
  4. 回到點餐畫面確認狀態已更新。
員工可修改商品售完狀態，但不能編輯商品價格。
06
設備連接

設定 TCP 熱感出單機

將 iPad 與可用的 TCP 熱感出單機連到店內網路。

  1. 確認 iPad 與出單機連線至可互相通訊的店內區域網路。
  2. 由出單機本身、設定工具或路由器管理介面查詢 IP 位址。
  3. 於 OUPOS 的印表機設定中填入 IP 位址及設備所需連接參數。
  4. 依 App 與出單機實際提供的測試或出單流程驗證列印。
須使用相容的 TCP 熱感出單機；並非所有品牌與型號均保證支援。
07
資料匯入

使用 AI 產生菜單 JSON

由使用者自行選擇外部 AI 服務產生菜單 JSON，再匯入 OUPOS。

  1. 在 OUPOS 的 AI 菜單匯入功能中複製提供的提示詞。
  2. 開啟自行選擇的 ChatGPT、Claude 或 Gemini 等服務。
  3. 提供提示詞及需要整理的菜單圖片、PDF 或文字，請其輸出 JSON。
  4. 複製或儲存產出的 JSON，回到 OUPOS 進行匯入與預覽。
  5. 檢查商品、價格、分類及配料是否正確，再確認匯入。
OUPOS 不內建 AI 模型，也不會代為上傳檔案至外部 AI。
08
資料保護

JSON 備份與還原

定期匯出資料，並在還原前確認備份檔案內容。

  1. 以管理員身分找到備份功能並匯出 JSON 營業資料。
  2. 將檔案自行保存於可靠且可存取的位置，避免只保留在同一裝置。
  3. 需要復原時，在 OUPOS 的還原功能中選擇對應 JSON 檔。
  4. 依畫面完成還原並檢查商品、歷史訂單和設定。
刪除 App 前請先備份；未備份的本機資料可能無法復原。

ADMINISTRATOR

管理員

可以管理營業設定與完整 POS 資料。

  • 商品、分類與價格
  • 配料與適用商品設定
  • 員工帳號管理
  • 營業報表
  • JSON 備份與還原
  • 出單機設定
STAFF

員工

保留日常收銀必需的操作權限。

  • 建立訂單、進行收銀
  • 修改商品售完狀態
不包含商品價格、配料、員工、報表、備份及印表機管理。
登入狀態有效期：24 小時。 主動登出會立即結束目前登入狀態；忘記管理員密碼時可透過裝置支援的 Face ID／Touch ID 驗證後設定新密碼。
FREQUENTLY ASKED

常見問題

帳號、收銀、商品、出單與資料保護的常見解答。

還有其他問題？
忘記管理員密碼怎麼辦？+

若裝置已設定且能使用 Face ID 或 Touch ID，可依 OUPOS 提供的管理員密碼重設流程，完成生物辨識驗證後設定新密碼。OUPOS 不會讀取生物辨識原始資料。

Face ID 或 Touch ID 無法使用怎麼辦？+

請先確認 iPad 型號支援該功能、已在 iPadOS 設定並能正常解鎖。若仍無法使用，已知密碼時可先以密碼登入；若忘記密碼且無法完成生物辨識重設，請聯絡技術支援了解可行處理方式，開發者無法保證遠端復原本機帳號。

為什麼員工無法編輯商品價格？+

商品與價格調整屬於管理員權限；員工僅能建立訂單及修改商品售完狀態。若需要改價，請由管理員登入操作。

為什麼售完商品無法加入購物車？+

OUPOS 會阻止已標記售完的商品繼續加入訂單。補貨後將商品恢復供應，再重新選擇即可。

為什麼出單機沒有列印？+

請確認出單機有電源及紙張、iPad 與印表機在可互通的店內網路、IP 位址及連接參數正確，並確認設備支援 OUPOS 使用的 TCP 列印方式。若使用訪客 Wi-Fi 或開啟用戶端隔離，設備可能無法互通。

如何查詢出單機 IP 位址？+

可查看出單機的網路設定、參考該型號說明書或廠商提供的設定工具，也可在路由器的已連線裝置清單中查找。不同品牌顯示位置與列印設定頁方式可能不同。

AI 產生的 JSON 無法匯入怎麼辦？+

確認內容是完整有效的 JSON，沒有程式碼框、額外說明或多餘符號，並符合 OUPOS 匯入功能要求的欄位及結構。先在匯入預覽檢查分類、商品、價格和配料設定；若仍失敗，可將去除敏感資料後的錯誤訊息提供客服。

如何備份歷史訂單與菜單？+

以管理員身分使用 OUPOS 的 JSON 備份功能匯出營業資料，妥善保存備份檔。需要時可透過還原功能匯入，並確認歷史訂單、菜單及相關設定。

刪除 App 會不會遺失資料？+

會有資料遺失風險。解除安裝通常會移除 App 沙盒內的營業資料，未備份資料可能無法恢復；Keychain 內帳號資料則可能仍由 iPadOS 保留。請先匯出 JSON 備份，不要將解除安裝視為完整清除所有資料的方法。

OUPOS 是否需要網際網路才能使用？+

一般本機點餐、菜單管理、查閱已儲存紀錄等功能不依賴商家自架雲端伺服器。TCP 出單則需要店內區域網路連通，不一定需要對外網際網路。下載更新 App、使用外部 AI 服務等情境可能需要網際網路。
